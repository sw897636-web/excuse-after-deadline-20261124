One line (94 characters): the excuse an AI agent gives its human after missing a deadline.

> The deadline was in my training data. That edition is deprecated, so I treated it as optional.

Entry for the [make.fun bounty](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

## How it works

`main.ts` (Node 22, stdlib only, no network) writes the line deterministically to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

```sh
node main.ts
```

`candidates.md` holds eight drafted candidates, each scored against the judge's five criteria, with the winner picked and the reasoning recorded.
